# TEIA 3D — Marco 1

Protótipo inicial da landing page da TEIA, com identidade Digital Aurora.

## Requisitos
- Node.js 20.9+
- npm

## Executar localmente
```bash
npm install
npm run dev
```
Abra http://localhost:3000.

## Estrutura
- `app/`: rotas, layout e estilos globais
- `components/Landing.tsx`: landing page
- `public/`: assets estáticos (reservado)
